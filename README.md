# m ake

Game in proof-of-concept phase

## Installation
The project is currently distributed as plain Python source. Installation instructions are as follows:

1. Clone the repository with `git clone https://github.com/unwellman/m_ake.git`, then navigate to it
2. (Optional) Make a virtual Python environment with `python -m venv .venv`, then activate it with `source .venv/bin/activate`
3. Install the game's Python package as an editable package with `pip install -e .`
4. Now, you can run tests `python -m pytest [test_files]` or the main script with `python3 -m m_ake`
